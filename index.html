03 / projects

Projects & achievements

CodeZela internship AWS · Wazuh 4.14 · Linux

SOCWatch Lab — Wazuh SIEM on AWS

A working Security Operations Center in the cloud, built during my CodeZela internship. I deployed the Wazuh 4.14 manager on AWS (EC2, VPC, IAM) and enrolled three endpoints — Ubuntu, Debian and Windows Server 2022 — to Active. I validated log ingestion, file-integrity monitoring, CVE vulnerability detection and SSH brute-force rules (Rule 5712, Level 10), then captured a real internet-sourced brute-force attack as evidence and delivered a report, runbook and presentation deck.

Hard lesson: stopped instances still bill for EBS + the Elastic IP. Now I terminate, keep AMIs, and run a $10/month AWS Budget with alerts.
